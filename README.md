# Neon Nexus Challenge

Build a 3-page draft website for an inter-school tech/hacking competition (working title "INTERSCHOOL CTF 2026" — placeholder, will be swapped later). Aesthetic reference: dark cyberpunk hacker-club sites like Exun Clan, CORE, Xino, Ncrypt — NOT generic corporate. Dark near-black background (#0a0a0f), neon accent (electric green #39FF14 or cyan #00F0FF, pick one as primary + a purple #A855F7 secondary), monospace/terminal font for headings (JetBrains Mono or Space Mono via Google Fonts), clean sans-serif for body. Subtle animated grid/circuit-board background or faint code-rain effect on hero, glitch-hover effect on nav links and buttons, glowing border accents on cards, smooth scroll-reveal animations.

This project was built with [Lovable](https://lovable.dev).
